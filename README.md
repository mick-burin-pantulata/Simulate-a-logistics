# LogiSim Factory — จำลองเมืองโรงงานและโลจิสติกส์ 3 มิติ

การจำลองโลจิสติกส์แบบ 3 มิติ (มุมมอง isometric) ของโรงงานขนาดกลางที่ตั้งอยู่กลางเมืองเล็ก ๆ (~1×1 กม.) สร้างด้วย **React, Three.js, React Three Fiber, TypeScript และ Zustand**

## เมืองโรงงาน — ห่วงโซ่อุปทานครบวง

- **ซัพพลายเออร์ 3 แห่ง** (บรรจุภัณฑ์ เคมี เหล็ก) ผลิตวัตถุดิบ → ฝ่ายจัดซื้อสั่ง (PO) เมื่อวัตถุดิบต่ำกว่าจุดสั่งซื้อ → รถบรรทุกไปรับที่ซัพพลายเออร์แล้วมาส่งโรงงาน
- **โรงงาน** รับวัตถุดิบเข้าคลัง → AGV ป้อนวัตถุดิบเข้าไลน์ผลิตทางสายพานฝั่งตะวันตก → ผลิตเป็นสินค้า → สายพานฝั่งตะวันออกกลับเข้าคลัง
- **ร้านค้า 5 แห่ง** ขายให้ชาวเมือง → สั่งของ (SO) เมื่อสต็อกต่ำ → รถบรรทุกรับสินค้าจากโรงงานไปส่งถึงร้าน
- **ชาวเมือง** อยู่บ้านเดี่ยวและคอนโดทางเหนือ ขับรถไปซื้อของตามช่วงเวลา พนักงานโรงงานขับรถจากบ้านมาจอดที่ลานจอดพนักงานตามกะ
- **ถนนตาราง + ไฟจราจร 6 แยก** — รถบรรทุกและรถยนต์ทุกคันใช้กราฟถนนเดียวกัน ขับชิดซ้าย หยุดไฟแดง และหลบกันโดยไม่ติดตาย
- ทดสอบแบบ headless 2 วันในเกม: ไม่มีรถติดตาย, ฝ่าไฟแดง 0 ครั้ง, ร้านไม่ขาดของ, ผลิต ≈ ขาย, พนักงานถึงที่ทำงานตรงเวลา

## Workflow ในโรงงาน

- **เวลา กลางวัน–กลางคืน** — 1 วินาทีจริง = 20 วินาทีในเกม (1 วัน ≈ 72 นาทีที่ 1×, ≈ 2¼ นาทีที่ 32×) แสงอาทิตย์/ดวงจันทร์เปลี่ยนตามเวลา กลางคืนไฟถนน ไฟอาคาร ไฟหน้ารถติด
- **กะทำงาน** — กะเช้า 07–19, กะดึก 19–07, สำนักงาน 08–17 พนักงานขับรถมาจอดที่ลานจอด เดินเข้าจุดประจำ พักทานข้าวที่โรงอาหารตามรอบ แล้วเดินกลับเมื่อเลิกงาน (ส่งต่องานระหว่างกะ)
- **รับวัตถุดิบ (PO)** — รถมาจากซัพพลายเออร์ → รปภ. ตรวจเอกสาร → เข้าท่า/รอคิว → พนักงานลากพาเลทด้วยแฮนด์ลิฟต์ → เจ้าหน้าที่ QC สแกนตรวจ → AGV นำเข้าชั้นวาง
- **ส่งสินค้า (SO)** — ร้านค้าสั่ง → รถมาถึงจึงเริ่มหยิบ → AGV หยิบลงช่องพัก → โหลดขึ้นรถ → ตรวจออกที่ประตู → ไปส่งที่ร้าน
- **ผังสมมาตร + ทางเข้า–ออกคนละฝั่ง** — รถวิ่งทางเดียวตะวันตก → ตะวันออก: เข้าประตูตะวันตก → ลานพักรถ P1–P5 (คิว) → ท่าโหลด 6 ท่า (รับ R1–R3 / ส่ง S1–S3) → ลานตรวจปล่อย C1–C5 (ชั่งน้ำหนัก/ซีลตู้) → ออกประตูตะวันออก มี รปภ. ประจำทั้งสองประตู
- **ระบบคิว** — ท่าเต็มรถไปจอดลานพักรถ แล้วถูกเรียกเข้าท่าแบบ FIFO; ลานพักเต็มรถรอที่ประตูและต่อแถวบนถนน
- **คนขับรถ** — ลงจากรถถือเอกสารไปห้องพักคนขับ รอจนงานเสร็จแล้วเดินกลับขึ้นรถ รถออกได้เมื่อคนขับกลับมา
- **ลำเลียง** — AGV ป้อนวัตถุดิบ → ไลน์ผลิตเติมกล่องลงพาเลท → พนักงานพันฟิล์ม → สายพานผ่านสะพานเข้าคลัง → AGV รับไปจัดเก็บ
- **ไม่มีคนเดินมั่ว** — ทุกคนมีตำแหน่ง กะ และจุดประจำ: ท่าโหลด, QC, ฝ่ายผลิต, สำนักงาน, รปภ., คนขับ

## UI

แท็บ ภาพรวม / เมือง / ออเดอร์ / คิวรถ / ท่าโหลด / AGV / คลัง-ผลิต / บุคลากร / ตั้งค่า, ป้ายลอยเหนือรถ, กรอบเลือกเรืองแสง, เส้นทางเรืองแสง, บันทึกเหตุการณ์, มุมกล้องสำเร็จรูป (ทั้งเมือง / บ้าน / ร้านค้า / ซัพพลายเออร์ / โรงงาน …) และปรับความต้องการ จุดสั่งซื้อ รอบไฟเขียวได้

รายละเอียดว่าแต่ละส่วนอยู่ไฟล์ไหน ดู [GUIDELINE.md](GUIDELINE.md)

## เริ่มใช้งาน

ต้องใช้ Node.js 20 ขึ้นไป

```bash
npm install
npm run dev
```

เปิด http://localhost:5173

| คำสั่ง | ทำอะไร |
| --- | --- |
| `npm run dev` | รันเซิร์ฟเวอร์สำหรับพัฒนา |
| `npm run build` | ตรวจ type แล้ว build ไปที่ `dist/` |
| `npm run typecheck` | ตรวจ type อย่างเดียว |

## โครงสร้างโปรเจกต์

แยกตามฟีเจอร์ — แต่ละฟีเจอร์มี logic, `scene/` (3D) และ `ui/` (แผงข้อมูล) ของตัวเอง

```
src/
  app/          Canvas, กล้อง, ตัวขับการจำลอง
  core/         คณิตศาสตร์, เส้นทาง (Path), BFS บนกริด
  world/        สถานะรวม, tick ทุกฟีเจอร์, snapshot สำหรับ UI
  store/        Zustand store
  features/
    time/       นาฬิกาเกม กะ แสงกลางวัน–กลางคืน
    roads/      กราฟถนนในเมือง การหาเส้นทาง
    traffic/    ไฟจราจร การหลบกัน รถยนต์ชาวเมือง
    city/       ผังเมือง บ้าน ร้าน ซัพพลายเออร์ ลานจอด
    stores/     สต็อกร้านค้าและการสั่งของ
    suppliers/  การผลิตวัตถุดิบและใบสั่งซื้อ
    residential/ พนักงานกับบ้าน การเดินทาง การไปซื้อของ
    orders/     เอกสาร PO / SO
    site/       ผังไซต์โรงงาน รั้ว อาคาร ประตู ป้ายพื้น
    warehouse/  ชั้นวาง สต็อก
    docks/      ท่าโหลด ช่องพัก งานพนักงานท่า QC
    agv/        รถยก AGV และคิวงาน
    trucks/     เส้นทาง คิว ลานพักรถ คนขับ ไม้กั้น
    workers/    กะ การเดินทาง หน้าที่ของแต่ละตำแหน่ง
    production/ ไลน์ผลิต เครื่องจัดพาเลท
    conveyor/   สายพานสินค้า (เข้าคลัง) และสายพานวัตถุดิบ (เข้าไลน์)
  shared/       ธีมสี, ป้ายลอย, กรอบเลือก, เส้นทาง, texture
  ui/           แถบบน, แถบข้าง, inspector, บันทึกเหตุการณ์
```

ตรรกะการจำลองแยกจากการแสดงผล: `world/world.ts` เดินเวลาทีละ ≤ 0.05 วินาที, ฉาก 3D อ่านสถานะทุกเฟรมผ่าน `useSimStore.getState()` และ UI อ่าน snapshot ที่อัปเดต 4 ครั้ง/วินาที
