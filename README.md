# LogiSim Factory — จำลองโลจิสติกส์โรงงาน 3 มิติ

การจำลองโลจิสติกส์ของโรงงานขนาดกลางแบบ 3 มิติ (มุมมอง isometric) สร้างด้วย **React, Three.js, React Three Fiber, TypeScript และ Zustand**

## ฟีเจอร์

- **รถบรรทุกเข้า-ออก** — วิ่งตามถนน รอ รปภ. ตรวจที่ประตู ไม้กั้นยกขึ้น ถอยเข้าท่า (ตัวพ่วงหักเลี้ยวแยกจากหัวลาก) แล้วออกจากโรงงาน
- **รับ-ส่งสินค้า**
  - ขาเข้า: พนักงานขนพาเลทจากรถ → ช่องพัก → รถยก AGV นำเข้าชั้นวาง
  - ขาออก: AGV หยิบจากชั้นวาง → ช่องพัก → พนักงานโหลดขึ้นรถ
- **คน** — พนักงานท่าโหลด, พนักงานฝ่ายผลิต, พนักงานเดินในไซต์ และ รปภ. พร้อมท่าเดินและท่ายกของ
- **ไซต์โรงงาน** — คลังสินค้า, ฝ่ายผลิต (สายพาน + เครื่องจักร), สำนักงาน, โรงอาหาร, ลานจอดรถ, อาคารสาธารณูปโภค
- **UI** — แดชบอร์ดแยกแท็บ (ภาพรวม / รถบรรทุก / ท่าโหลด / AGV / คลังสินค้า / บุคลากร / ตั้งค่า), ป้ายลอยเหนือรถ, กรอบเลือกเรืองแสง, เส้นทางเรืองแสง, บันทึกเหตุการณ์ และมุมกล้องสำเร็จรูป

## เริ่มใช้งาน

ต้องใช้ Node.js 20 ขึ้นไป

```bash
npm install
npm run dev
```

เปิด http://localhost:5173

| คำสั่ง | ทำอะไร |
| --- | --- |
| `npm run dev` | รันเซิร์ฟเวอร์สำหรับพัฒนา |
| `npm run build` | ตรวจ type แล้ว build ไปที่ `dist/` |
| `npm run typecheck` | ตรวจ type อย่างเดียว |

## โครงสร้างโปรเจกต์

แยกตามฟีเจอร์ — แต่ละฟีเจอร์มี logic, `scene/` (3D) และ `ui/` (แผงข้อมูล) ของตัวเอง

```
src/
  app/          Canvas, กล้อง, ตัวขับการจำลอง
  core/         คณิตศาสตร์, เส้นทาง (Path), BFS บนกริด
  world/        สถานะรวม, tick ทุกฟีเจอร์, snapshot สำหรับ UI
  store/        Zustand store
  features/
    site/       ผังไซต์ ถนน รั้ว อาคาร ประตู ป้ายพื้น
    warehouse/  ชั้นวาง สต็อก
    docks/      ท่าโหลด ช่องพัก งานพนักงานท่า
    agv/        รถยก AGV และคิวงาน
    trucks/     เส้นทาง การถอยเข้าท่า ไม้กั้น
    workers/    พฤติกรรมคนแต่ละตำแหน่ง
    production/ ไลน์ผลิต
  shared/       ธีมสี, ป้ายลอย, กรอบเลือก, เส้นทาง, texture
  ui/           แถบบน, แถบข้าง, inspector, บันทึกเหตุการณ์
```

ตรรกะการจำลองแยกจากการแสดงผล: `world/world.ts` เดินเวลาทีละ ≤ 0.05 วินาที, ฉาก 3D อ่านสถานะทุกเฟรมผ่าน `useSimStore.getState()` และ UI อ่าน snapshot ที่อัปเดต 4 ครั้ง/วินาที
